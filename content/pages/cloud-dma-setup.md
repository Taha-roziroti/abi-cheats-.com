# Cloud DMA setup for Arena Breakout Infinite

Hyper-V walkthrough for single-PC Cloud DMA: confirm virtualization, reserve resources, finish activation, then verify before launching ABI.

## Before you start

- Windows 10 or 11 with Hyper-V capable CPU and virtualization enabled in firmware
- Review [Cloud DMA requirements](/cloud-dma-for-arena-breakout-infinite/) and the [ABI cheats homepage](/) for listed Windows and security settings

## Setup steps

1. Enable Hyper-V and confirm no conflicting hypervisors are running on the host PC.
2. Allocate RAM and storage for the virtual machine per the seller’s Cloud DMA documentation.
3. Complete activation steps from your order email, then reboot if the guide requires it.
4. Verify the VM can reach the network, then follow the cheat loader instructions before opening Arena Breakout Infinite.

## After setup

Re-check requirements after major Windows updates. Keep Cloud DMA and ABI licenses on separate checkout receipts so renewal dates stay clear.
